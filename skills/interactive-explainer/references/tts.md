# 语音选择与时间轴

只在需要配音时读取并执行。用户已选提供方就沿用；普通联网讲解、没有指定音色时，可优先选择 Edge TTS，先用含术语和数字的一小段检查效果。

## 可选路径

| 选项 | 适用情况 | 取舍 |
| --- | --- | --- |
| **无配音** | 参数实验、手动分步或阅读型 HTML | 用步骤或作者设定的节奏；没有 TTS、模型与音频依赖 |
| **Edge TTS** | 希望快速获得普通中文或多语言旁白 | 调用在线服务；讲稿会发送到服务端，不需要本地 GPU；实际可用音色先查询 |
| **现有 CosyVoice3** | 需要现有参考音色、讲解风格控制，或在已有本地环境合成 | 使用已安装模型；核对运行环境、资源及参考音频；启动和维护成本较高 |
| **已有录音 / 用户指定的其他 TTS** | 用户已有音轨，或指定了声音、服务 | 复用素材，测量并对齐；按该服务的实际接口接入同一音频清单 |

浏览器 `speechSynthesis` 可用于明确接受系统声音差异的临时预览；其音色和时序依赖浏览器与系统，不作为可复现视频的默认音轨来源。

## Edge TTS

`edge-tts` 是第三方 Python 客户端，调用 Microsoft Edge 的在线语音服务；不要把它写成 Azure Speech 官方 SDK，也不要假定其拥有生产 SLA。具体参数以当前安装版本为准。

在项目隔离环境安装后，可用下面的 CLI 形式；`EXPLAINER_VOICE` 填入查询确认的音色名，`utterance.txt` 是 UTF-8 讲稿：

```bash
edge-tts --list-voices
edge-tts --file utterance.txt --voice "$EXPLAINER_VOICE" \
  --rate=+0% --write-media utterance.mp3 --write-subtitles utterance.srt
```

也可用 Python `edge_tts.Communicate` 逐段生成。只用客户端支持的音色、语速、音高等参数，不假设支持任意 SSML。命令及限制参考 [项目说明](https://github.com/rany2/edge-tts) 和 [CLI 实现](https://github.com/rany2/edge-tts/blob/master/src/edge_tts/util.py)。

空文件、只有头部或不能解码的响应都算失败。采用有限重试（例如最多三次、逐次退避），验证成功才原子写入缓存；失败段保留诊断，其他成功段可复用。耗尽后报告具体段落与影响，不把空音频当成功，也不静默切换到付费服务或违背既有离线要求。

## CosyVoice3

优先调用现有安装，使用其已验证的批处理入口或 API。若选择 Axiom，先按仓库 `environments` 指引确认目标主机、模型和 GPU 资源；模型初始化一次，随后批量处理片段。不要为每句话重复加载模型，也不为这个 Skill 自动部署常驻服务。

按已安装版本核对指令合成、参考音频和速度参数，记录实际模型版本及参考音频哈希。使用可用且获授权的参考素材。上游能力与示例见 [CosyVoice](https://github.com/QwenAudio/CosyVoice)；不把特定模型 API 或过去一次路径当成通用接口。

## 提供方无关的流程

1. 按讲解动作切成自然的句子或短段，不逐字合成。分别保存展示文本与实际朗读文本；缩写、数字或单位的读法替换不能改变含义。
2. 先生成包含关键数字和术语的小样，检查效果符合目标后生成其余片段。不要为每种提供方都生成全套。
3. 缓存键覆盖实际朗读文本、提供方、音色/模型、语速、音高、音量、指令、参考音频哈希、输出格式与相关前处理版本。记录可获得的库/模型版本；在线服务版本未知时如实记录，复用已验证音频。
4. 检查每段可解码、有声音、时长合理；按最终剪裁和变速结果测量时长。裁静音需保留发音和自然停顿，不能只按能量阈值切掉弱音。
5. 把片段实际时长、段间停顿、字幕与动画提示写到共享时间轴。服务返回的局部字幕边界需加片段偏移，并随裁剪或变速重新换算；不按字数猜最终长度。
6. 统一音频格式后合成；响度目标随用途选择，例如旁白可取约 −17 LUFS，并检查峰值与首尾完整性。这是制作参数，不是所有平台的统一标准。

清单至少保留片段 ID、两种文本、提供方配置、文件哈希、解码时长、时间线起止和验证状态。改配音后更新受影响的时间轴、字幕与导出缓存，不能复用旧时长。

重点核对小数、百分比、货币单位、否定词与专名。ASR 可帮助发现误读或缺词，但转写也可能出错；不要仅用字符串相似度判定质量，更不要声称完成未执行的人工听审。

无语音 HTML 用步骤或作者设定的时长即可完成。用户明确要有声成品而 TTS 失败时，可保留可用 HTML 作为中间产物，同时说明音轨尚未完成，不能把降级交付算作满足原要求。
