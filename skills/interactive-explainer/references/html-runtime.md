# HTML 运行与交付

用于制作交互式讲解，以及让同一场景支持视频导出。网页的任务是帮助读者理解，不只是播放已渲染的视频。

## 设计读者的操作

按概念选择交互，不为凑功能增加控件：

| 解释的问题 | 合适的操作 | 应看到的结果 |
| --- | --- | --- |
| 一件事先后怎样发生 | 单步、拖动时间、重放 | 当前事件、已知信息、状态同步改变 |
| 一个变量为何改变结论 | 有范围和单位的参数控件 | 图形、计算结果和解释同时更新 |
| 两种情况差在哪里 | 固定基准，对照另一组参数 | 明确哪些条件改变，哪些保持一致 |
| 一条公式怎样推出 | 分步展开、局部强调、代入数值 | 符号与图中对象对应，能检查中间值 |

引导模式给出阅读顺序和解释；探索模式允许读者停下来改变条件。保留返回默认示例或重置的入口。无需自动播放的内容可以只用步骤与参数，不先制造一条音频时间轴。

例如解释采样混叠：固定原信号，拖动采样频率，让采样点与可能的重建波形同时更新，并说明输入带宽这一前提。此类 HTML 独立成立，不需要先生成配音或 MP4。

## 共享状态与时间

数据、模型、展示状态分开。图表、关键数字、文字解释与辅助表格从同一个状态计算，避免各处复制公式。

有时间线时，可采用以下接口约定；名称可沿用项目：

```ts
type Scenario = Readonly<Record<string, number | string | boolean>>;

interface Explainer {
  ready: Promise<void>; // 数据、字体、图片等实际必需资源就绪
  durationSeconds: number;
  render(tSeconds: number, scenario: Scenario): void | Promise<void>;
}
```

同一时间、场景参数、数据和资源应产生同一画面，与之前访问过哪个时刻无关。导出时显式传入冻结参数，不能继承播放器上次交互留下的可变默认值。随机内容固定种子。

- **无声播放：** `requestAnimationFrame` 可驱动预览，但先计算显式时间，再调用渲染函数。暂停与手动拖动不应继续累积时间。
- **有声播放：** 以媒体实际播放位置驱动画面；等待用户播放动作，处理 `audio.play()` 被拒绝或加载失败。不要同时运行另一条会漂移的计时器。[播放行为](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)
- **探索：** 改变参数后重算画面。如果旁白只适用于原示例，先暂停声音并显示新的解释；回到引导模式时恢复相应参数和时间。
- **导出：** 停止所有自动播放；渲染函数提交完 DOM、SVG 或 Canvas 后才返回。CSS 动画也需暂停并显式定位，不能依赖页面加载后过了多久。

保持“讲解时间”和“被解释事件的时间”两个概念。例如视频第 40 秒可对应事件发生后 2.7 秒，坐标轴应说明后者的单位与零点。

## 连续动画

先让观众认出对象，再改变对象的关系：点沿时间轴移动、数量拆分或合并、公式与图形对应、同一图形缩放到局部。转场保留对象身份；必要文字留足阅读时间。

视觉插值只作用于展示。阶梯数据仍按历史更新时刻跳变，未知区间保留缺口。对照假设使用独立状态与可见标识，不覆盖原始事实。

固定视频舞台和交互网页可共用模型与场景，但网页要保持控件和解释可读。窄屏可重排文字与控件，或提供查看大图的入口，不把桌面内容整体缩成难以辨认的小字。

## 单文件与静态目录

**单文件 HTML** 适合体量较小、需要离线打开和分享的讲解。内嵌所需数据、打包后的 JS/CSS、字体及可选音频。仅设置构建工具的相对路径不等于自包含；模块 import、`fetch()`、`../font.woff2` 和 CDN 仍可能在双击时失效。

内嵌资源增加体积与内存占用，较大音频、视频或数据可改交静态目录和明确的本地启动命令。用户只要本地成品时无需自动部署到公网。

保留字体与素材许可证。等待字体真正加载后再截图；`document.fonts.ready` 是等待入口，还需检查目标字体加载状态，不能把回退字体误当成成功。[字体加载](https://developer.mozilla.org/en-US/docs/Web/API/Document/fonts)

在实际浏览器检查：

- 从承诺的入口打开交付副本，确认资源成功加载；声称离线时在无既有缓存或 Service Worker 的干净浏览器上下文中切断网络验证，避免缓存掩盖资源缺失。
- 操作实际控件，并检查图形、解释与数值一致；确认重置、末尾停止和再次播放合理。
- 对时间线跳到 `t1 → t2 → t1`，固定参数比较两次 `t1`；另验证改变参数后能回到原场景。
- 检查关键状态的截图、控制台和资源请求。DOM 桩和构建检查补充功能证据，不能代替真实浏览器外观检查。
