# 视频导出与验证

仅在用户需要视频时执行。HTML 已经满足需求时，不安装渲染依赖、不调用 TTS，也不为了“完整流程”额外生成 MP4。

## 固定导出输入

记录数据与场景版本、参数、随机种子、时间轴、字体、浏览器、画幅、帧率和编码配置。一个视频导出固定一个场景参数集；参数变化的演示也要明确写入时间线。

按用途选择画幅与帧率，讲解可从 1920×1080、30 fps 起步。动画复杂度、字幕字号、CPU/GPU 与浏览器截图成本都影响速度，不承诺过去某次任务的渲染耗时。

无声内容可用作者时长；有声内容先得到最终音轨。用户指定总时长时保留该约束，按最终实测音频重排段落、停顿与画面：音频较短可安排结尾停留，超时则先解决讲稿、语速与时长的冲突，不能截掉旁白或擅自改变总长。未指定总时长时，由最终音轨与必要停顿确定讲解长度。

令帧数 `N = ceil(durationSeconds × fps)`，帧编号为 `0 … N−1`，第 `i` 帧在 `i / fps` 渲染。总长为 `N / fps`，必要时给音轨末尾补短静音；不要多输出一帧终点或用截断掩盖长度错误。

## 浏览器逐帧渲染

使用 Playwright/Chromium 或当前可用的等价浏览器自动化能力：

1. 加载确定的页面和资源，固定 viewport、设备像素比与字体；等待场景 `ready`。
2. 停止预览播放器与媒体自动计时，隐藏不属于成片的操作控件；保留字幕、图注和来源说明。
3. 显式传入该帧时间与冻结参数，等待 DOM/Canvas 绘制完成，再截图指定舞台。
4. 截图缓冲直接送入 FFmpeg 管道，或使用可控大小的帧序列目录。处理管道背压与失败；不要默认将长片全部未压缩帧写满磁盘。

下面是调用契约示意，需接入实际页面与编码进程：

```js
await page.evaluate(() => window.explainer.ready);
for (let i = firstFrame; i < lastFrameExclusive; i++) {
  await page.evaluate(async ({ t, scenario }) => {
    await window.explainer.render(t, scenario);
  }, { t: i / fps, scenario: frozenScenario });
  const image = await page.screenshot({ type: 'png' });
  await writeFrameWithBackpressure(image);
}
```

React 场景可在这个外部捕获入口同步提交，或返回提交完成的 Promise；截图不能抢在框架更新之前。CSS/Web Animations 也应显式设置进度。浏览器截图接口见 [Playwright](https://playwright.dev/docs/screenshots)。

较长任务可按整数帧区间分块并行，每块使用独立页面和相同配置。检查区间既不重叠也不缺帧，合并时保持帧率、时间基与编码参数一致。并行数按实际资源和瓶颈决定。

## 编码与声音

- 使用 FFmpeg 编码常见的 H.264 / yuv420p 视频与 AAC 音轨；有可用 NVIDIA 环境时可选 NVENC，无 GPU 时使用可用的软件编码器。
- 截图输入帧率要显式指定，不能依赖默认值；尽量保持分段帧时长与时间基一致，避免拼接累计偏移。
- 字幕可绘入 HTML 舞台，另提供 SRT；需要可关闭字幕时按容器能力封装字幕轨。输出字幕必须来自最终时间轴。
- 配音与画面从同一零点开始。合成后检查编码器延迟、末尾填充和实际时间戳；不要仅用 `-shortest` 掩盖丢失旁白。
- 按需求添加章节和快速起播元数据；音频响度统一后检查峰值。无需自动加背景音乐或装饰音效。

## 验证与交付

先验证一个代表片段的分镜、文字和声音，再渲染全片；这是一种降低返工的方法，不是用户每次都需批准的关卡。

- **可重复定位：** 固定环境和参数，比较 `t1 → t2 → t1` 的画面；重启页面后复核关键时刻，排除隐含状态。
- **真实成片：** 完整解码；用 ffprobe 检查分辨率、帧率、帧数、音画时长与章节。检查实际解码/播放时间，不只看文件名或容器总体时长。
- **视觉：** 抽查开头、结尾、转场两侧、公式与关键数据帧；看实际编码后的文件，确认图注、字幕、坐标和控件没有遮挡。
- **语音：** 核对关键段落、数值、首尾及字幕位置。明确机器转写和实际听审各自做到了什么。
- **传输：** 跨机器复制后核对文件大小与哈希；交付实际存在的文件，不把正在渲染的任务算完成。

视频交付以 MP4 为主入口；按用户需求附交互 HTML、逐字稿、字幕、源数据摘要或源码包。源码包排除模型权重、依赖缓存、临时帧和无关私有材料。说明反事实、假设与数据覆盖限制，不能把漂亮动画当成新的研究证据。
