# 轮次记录

下面是内容清单，按本轮实际需要精简；不要把未核实的条件填成事实。

## prompt.md

```text
最终目的：
本轮目标：
用户修正与既有决定：

现场：宿主、项目开发环境、绝对 cwd、当前提交与已有改动。
输入：相关代码、文档、上一轮结论及证据路径。
允许修改范围：
限制：不可触碰的内容、资源预算、联网/工具边界。

验收：可观察的行为、真实调用路径、应运行的检查。
交付：说明修改文件、行为变化、执行过的命令及结果、未完成项。
发现前提不成立时说明证据，不要自行改变最终目标或伪称通过验证。
```

## review.md（监督者写）

```text
轮次及记录路径：
执行状态：meta.json 结论，是否中断/恢复，是否需要检查残留进程。
pi 声明：
独立观察：diff、真实入口、数据流、潜在回归。
验证：监督者实际执行的命令、退出状态、关键结果和证据位置。
结论：接受 / 返工 / 阻塞；理由和未验证边界。
下一轮：目标、复现证据、验收要求。
```
